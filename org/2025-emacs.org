*** =org-qiita-export-buffer-to-book= の作成

後は =.org= ファイルからの Markdown ファイルの展開を実装します。幸い org ドキュメントの /subtree/ に対する /export/ という概念があり、 org-mode はこのような処理が得意です。

#+ATTR_TYPST: :breakable true
#+BEGIN_SRC elisp
(leaf ox-qmd
  :commands (org-qiita-export-buffer-to-book)
  :config
  ;; Converts org-mode tags into front matter tag.
  (defun qmd2-template-tags ()
    (let ((tags (or (mapcar #'substring-no-properties (org-get-tags))
                    "")))
      (string-join
       (mapcar (lambda (s) (format "\"%s\"" s)) tags)
       ",")))

  ;; Markdown file template for `@qiita/qiita-cli'.
  (defun qmd2-template (contents info)
    (let* ((title (or (substring-no-properties (car (plist-get info :title))) ""))
           (tags (qmd2-template-tags)))
      (concat
       "---\n"
       "title: \"" title "\"\n"
       "tags: [" tags "]\n"
       "private: false\n"
       "updated_at: \"\"\n"
       "id: null\n"
       "organization_url_name: null\n"
       "slide: false\n"
       "---\n\n"
       contents)))

  ;; The Qiita Markdown export backend, built on top of `ox-qmd'.
  (org-export-define-derived-backend 'qmd2 'qmd
    :options-alist
    '((:title "TITLE" nil nil t)
      (:tags "TAGS" nil nil space))
    :translate-alist '((template . qmd2-template)))

  ;; Exports a subtree of org file into a Markdown file.
  (defun org-qmd2-export-to-markdown (&optional async subtreep visible-only)
    (interactive)
    (let ((outfile (org-export-output-file-name ".md" subtreep)))
      (org-export-to-file 'qmd2 outfile async subtreep visible-only)))

  ;; Exports each level 1 heading into a Markdown file.
  (defun org-qiita-export-buffer-to-book (&optional org-dir)
    "Runs subtree export to each level 1 heading, respecting `#+BOOK_DIR'."
    (interactive)
    (require 'ox-qmd)
    (let* ((default-dir default-directory)
           (pub-dir (car (cdr (car (org-collect-keywords '("BOOK_DIR")))))))
      (cd pub-dir)
      (unwind-protect
          (org-map-entries
           (lambda ()
             (let ((exports (org-entry-get nil "EXPORT_FILE_NAME")))
               (when exports
                 (org-qmd2-export-to-markdown nil t))))
           "LEVEL=1")
        (cd default-dir)))))
#+END_SRC

*** =find-file= で =consult-preview-key= を有効化する

早速 Embark ではなく Consult の設定ですが、 Wiki にある =consult-find-file-with-preview= 関数を定義すると、プレビュー機能付きの =find-file= ができます:

#+BEGIN_QUOTE
https://github.com/minad/consult/wiki#previewing-files-in-find-file
#+END_QUOTE

#+BEGIN_SRC elisp
(leaf consult
  :custom
  ;; `C-l` 押下にてプレビューを表示:
  (consult-preview-key  . "C-l")
  ;; 常にプレビューを表示:
  ;; (consult-preview-key  . "any")
  :init
  (progn ;; `find-file' with Consult preview
    ;; https://github.com/minad/consult/wiki#previewing-files-in-find-file
    (setq read-file-name-function #'consult-find-file-with-preview)
    (defun consult-find-file-with-preview (prompt &optional dir default mustmatch initial pred)
      (interactive)
      (require 'consult) ;; 追加しました
      (let ((default-directory (or dir default-directory))
            (minibuffer-completing-file-name t))
        (consult--read #'read-file-name-internal
                       ;; Enter でファイルが開けませんでした:
                       ;; :state (consult--file-preview)
                       ;; Preview でき、 Enter でファイルを開けます:
                       :state (consult--file-preview)
                       :prompt prompt
                       :initial initial
                       :require-match mustmatch
                       :predicate pred)))))
#+END_SRC

ただ、どうも上の定義だと =find-file= の挙動を変えるようで、ユーザ入力のテキスト中に PWD (=default-directory=) が表示されなくなります。 =../= を打てば上の階層に上がることもできますが、従来の =find-file= に慣れていると見通しが悪く感じます。

*** =find-file= と dired を行き来する (=embark-export=)

*** =find-file= と =consult-grep= を行き来する

ミニバッファを使う間を移動するキーバインドを作って行きます。

**** =find-file= -> =consult-ripgrep=

まず =find-file= から =consult-ripgrep= への移行を (AI が) 実装します。

Minibuffer を閉じてから、ユーザ関数を呼ぶためのユーティリティを定義します:

#+BEGIN_SRC elisp
  (defun my/abort-minibuffer-and-call (f)
    "Utility function for unwinding the minibuffer and call a function."
    (if (minibufferp)
        (progn
          (run-at-time 0 nil f)
          (abort-recursive-edit))
      (user-error "Not in a minibuffer")))
#+END_SRC

これを使って =find-file= から =consult-ripgrep= への移行を実装します:

#+BEGIN_SRC elisp
  (progn ;; `find-file' -> `consult-ripgrep'
    (defun my/consult-ripgrep-from-find-file ()
      (interactive)
      (let ((dir (file-name-directory (minibuffer-contents))))
        (my/abort-minibuffer-and-call
         (lambda () (consult-ripgrep dir ". ")))))
    (keymap-set minibuffer-mode-map "C-c g" #'my/consult-ripgrep-from-find-file))
#+END_SRC

Minibuffer では =C-c= のバインディングが空いていたため、 =C-c g= にバインドしました。

**** =consult-ripgrep= -> =find-file=

同様に、 =consult-ripgrep= から =find-file= への移行を実装します:

#+BEGIN_SRC elisp
  (progn ;; `consult-ripgrep' -> `find-file'
    (defun my/find-file-from-consult-ripgrep ()
      (interactive)
